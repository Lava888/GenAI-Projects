## 🚀 How to Use

1. **Install Jupyter**
   ```bash
   pip install jupyter ipython
   ```

2. **Launch Jupyter**
   ```bash
   jupyter notebook
   ```

3. **Open a notebook**
   - Click on desired `.ipynb` file
   - Run cells sequentially (Shift + Enter)
   - Modify and experiment

## 💡 Tips

- Run cells in order
- Modify prompts for your use case
- Print intermediate outputs for debugging
- Save as `.py` for production use: `File → Export`

## 🔧 Dependencies

All notebooks use packages from `requirements.txt`:
```bash
pip install -r ../requirements.txt
```
